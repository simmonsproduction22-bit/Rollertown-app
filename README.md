# Rollertown-app

Phone app concepts for North Texas breweries.

- `rollertown/`: Rollertown Beerworks (served at `/rollertown/`, uses the `/api` member accounts)
- `threeempires/`: Three Empires Brewing Co., Frisco (served at `/threeempires/`, only real Three Empires info: beers, weekly events, hours, story; no accounts or rewards)
